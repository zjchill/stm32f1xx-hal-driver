- 每个外设以 `stm32f1xx_hal_<peripheral>.h/.c` 成对提供，并通过 `__HAL_LINKDMA` 宏将 DMA 句柄绑定到外设句柄。
- 所有公开符号通过 Doxygen `@defgroup` / `@addtogroup` 分组文档化，并使用 `extern "C"` 包裹以支持 C++ 调用。
- 错误码统一返回 `HAL_StatusTypeDef`（`HAL_OK/HAL_ERROR/HAL_BUSY/HAL_TIMEOUT`），状态机字段命名遵循 `State` 语义并由宏复位。
- 板级初始化通过 `HAL_PPP_MspInit/Deinit` 回调函数交由用户实现，HAL 层仅在使能时调用该钩子。
- Legacy 兼容层通过同名 Legacy 头文件重定向到新版实现，保持旧 API 二进制兼容而不修改核心代码。
