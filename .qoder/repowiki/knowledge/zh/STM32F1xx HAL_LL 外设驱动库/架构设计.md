仓库按 STM32Cube 标准分层组织：
- `Inc/` 与 `Src/` 一一对应，每个外设一个头文件 + 源文件对，顶层入口为 `stm32f1xx_hal.h`（聚合所有 HAL 模块），公共类型、宏、句柄基结构定义在 `stm32f1xx_hal_def.h`。
- 每份 HAL 实现通过 `HAL_PPP_MspInit/Deinit` 等回调钩子调用用户代码，将平台无关的 HAL API 与具体板级配置解耦；模板文件 `stm32f1xx_hal_conf_template.h`、`stm32_assert_template.h`、`stm32f1xx_hal_msp_template.c`、`stm32f1xx_hal_timebase_tim_template.c`、`stm32f1xx_hal_timebase_rtc_alarm_template.c` 供工程复制后裁剪使用。
- 在 HAL 之下还包含 `stm32f1xx_ll_*.h/.c`（Low-Layer 直接寄存器访问层），由 HAL 内部按需调用，形成 HAL → LL → CMSIS/Core 的单向依赖。
- `Legacy/` 子目录保留旧版 HAL（如 CAN）以维持向后兼容，由同名 Legacy 头文件转发。
- 构建产物仅依赖 CMSIS Core/Device (`stm32f1xx.h`)，不含任何编译器或 IDE 特定脚本，作为纯 MCU Component 被上层工程引用。
